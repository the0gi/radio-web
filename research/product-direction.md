# Agreed direction

- General-purpose regional radio app; children’s stations are the initial catalog for home listening, not a children’s visual identity.
- Primary device: an older iPhone 7. Screen-locked listening is a required acceptance check on real hardware.
- English interface, standard bottom navigation on mobile, persistent player above it.
- Automatic appearance follows the operating system. Frosted surfaces, rounded cards and restrained blur inspired by the supplied Apple-style references.
- Proposed stack implemented for the prototype: React, TypeScript, Vite, plain CSS. Local favorites and static station catalog. No backend needed yet.
- First milestone: locally running listening prototype. Direct stream availability does not establish background playback reliability.
